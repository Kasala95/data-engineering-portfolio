Clinical Notes NLP Code Detection

A synthetic clinical NLP pipeline that creates review-ready candidate coding findings without using patient data.

Business Problem

Revenue cycle teams often need a targeted review workflow rather than broad manual review. This project demonstrates how text detection can identify candidate diagnosis codes from clinical-style notes and route uncertain findings for human review.

Architecture

Synthetic clinical notes and billed-code records
Terminology detection for diagnosis candidates
Comparison against billed-code fields
Human-review queue for missing candidate codes

Implementation Details

  • Uses 60 fake clinical notes, each generated without patient information.
  • Detects diagnosis terms and maps them to synthetic ICD-style candidate codes.
  • Flags only missing candidates, preserving a human review checkpoint.
  • Demonstrates compliance-aware NLP workflow design rather than automated billing decisions.

LinkedIn Project Summary

Built a synthetic NLP pipeline to process clinical-style notes and identify candidate diagnosis codes missing from billed-code records, with outputs designed for targeted human review.
