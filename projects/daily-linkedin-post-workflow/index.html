Daily LinkedIn Post Workflow

A scheduled content workflow that generates LinkedIn-ready daily technical posts with documentation diagrams.

Business Problem

Consistent technical visibility on LinkedIn is easier when the content process is repeatable. This project turns daily posting into a lightweight workflow with a topic calendar, templated post generation, diagram documentation, and a review checkpoint before publishing.

Architecture

Daily GitHub Actions cron trigger
Content calendar topic selection
LinkedIn-ready post and Mermaid diagram generation
Commit generated markdown for manual LinkedIn review

Implementation Details

  • Runs daily from GitHub Actions using a cron schedule.
  • Generates posts about data engineering, analytics engineering, governance, observability, revenue data, and healthcare ML.
  • Creates a date-stamped markdown draft and updates a latest-post file.
  • Includes Mermaid diagrams so each post can become a documentation carousel or visual explainer.
  • Keeps publishing manual unless LinkedIn API authorization is added later.

LinkedIn Project Summary

Built a scheduled workflow that generates daily LinkedIn-ready technical posts for a senior data engineering profile. The workflow uses GitHub Actions, a content calendar, repeatable post templates, Mermaid diagrams, and review-ready markdown outputs.
