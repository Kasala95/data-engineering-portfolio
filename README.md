# Ocholi Idakwo - Data Engineering Portfolio

This portfolio contains six end-to-end, GitHub-safe project recreations using synthetic data. Each project is designed to support a LinkedIn project entry and demonstrate senior data engineering judgment across analytics engineering, revenue data, governance, observability, and healthcare machine learning.

## Projects

| Project | What It Shows |
| --- | --- |
| [Customer 360 Analytics Platform](projects/customer-360-analytics-platform) | CRM modeling, customer marts, reusable SQL patterns |
| [SaaS Account Health Scoring](projects/saas-account-health-scoring) | Feature engineering, retention scoring, operational analytics |
| [Revenue Source Of Truth Model](projects/revenue-source-of-truth-model) | Finance data controls, FX normalization, reconciliation |
| [Data Quality And Observability Framework](projects/data-quality-observability-framework) | Automated validation, freshness checks, incident-ready reporting |
| [Healthcare Readmission Risk Pipeline](projects/healthcare-readmission-risk-pipeline) | Synthetic healthcare features, risk scoring, batch ML outputs |
| [Clinical Notes NLP Code Detection](projects/clinical-notes-nlp-code-detection) | Synthetic NLP detection, candidate-code review workflow |

## Public Data Disclaimer

All data is synthetic. This repository does not contain employer code, employer schemas, customer data, patient data, credentials, or confidential architecture.

## How To Run

From any project folder, run the Python script listed in that project's README. The scripts use only the Python standard library so they run without package installation.
